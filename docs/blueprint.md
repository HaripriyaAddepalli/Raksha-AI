# **App Name**: RAKSHA AI

## Core Features:

- Digital Scam Analysis Tool: An AI-powered interface that uses Gemini as a tool to parse transcripts and messages, returning risk scores and categorizing specific scam patterns like Digital Arrest or OTP fraud.
- Currency Authenticity Inspector: Analyze uploaded images of currency for security features and suspicious regions using vision-capable AI models to generate risk classification reports.
- Fraud Network Intelligence Visualization: Process CSV transaction data into interactive node-based network graphs to detect suspicious clusters and potential fraud rings using React Flow.
- Unified Safety Dashboard: A glassmorphic command center displaying real-time safety metrics, high-risk cases, and threat distribution using Recharts for visual intelligence.
- Investigation Persistence: Secure storage of all analyzed cases and history using MongoDB to maintain an audit trail of public safety intelligence.
- Case Export & PDF Generation: Generate comprehensive investigation reports for any detected fraud case, downloadable for professional law enforcement or internal reporting.
- Batch Fraud Processing: Capability to upload large datasets of communication or transactions for automated AI bulk scanning to identify wide-scale campaigns.

## Style Guidelines:

- Dark intelligence aesthetic centered on 'Cyber Command'. Background is a deep navy-midnight (#0b111f), providing a sophisticated void for glowing UI elements.
- Primary color is a high-contrast Intelligence Blue (#2563eb). Accent color is an analogous Cyan-Azure (#06b6d4) used for precision highlighting and data connectivity.
- Font pairing: 'Space Grotesk' for tech-oriented headlines and technical readouts; 'Inter' for readable, objective-looking body text and analysis reports.
- Crisp, monochromatic outline icons representing 'shield', 'radar', 'security-lock', and 'network-branching' for a professional agency feel.
- A high-density modular grid utilizing glassmorphic cards with subtle 1px borders and radial backdrops for depth and high-end visual hierarchy.
- Linear micro-interactions such as pulse indicators on 'active' threats and smooth spring transitions for network graph nodes.
