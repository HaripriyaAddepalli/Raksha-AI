 🛡️ RAKSHA AI - Digital Public Safety Intelligence

RAKSHA AI is an AI-powered public safety platform designed to combat digital fraud, counterfeit currency, and organized scam networks using Generative AI, visual intelligence, and data-driven analytics.

## 🌟 Overview

With the rapid rise of cybercrime, financial fraud, phishing attacks, and counterfeit currency circulation, individuals and organizations need intelligent tools to identify threats quickly and accurately.

RAKSHA AI provides a unified platform that leverages Generative AI, visual intelligence, and network analytics to detect scams, verify currency authenticity, and uncover suspicious fraud networks.

---

## 🚀 Key Features

### 🛡️ Scam Detector

Analyze suspicious messages, emails, and call transcripts using AI-powered threat intelligence.

* AI-powered fraud analysis using Gemini AI
* Risk scoring and threat assessment
* Detection of phishing attempts and scam patterns
* Actionable recommendations for users
* Reliable fallback mechanism during AI service interruptions

### 💵 Currency Inspector

Verify the authenticity of banknotes through advanced visual analysis.

* Detects security features
* Identifies watermarks and security threads
* Evaluates authenticity indicators
* Generates confidence scores and risk assessments

### 🕸️ Network Intelligence

Investigate suspicious transaction networks and identify hidden fraud clusters.

* Interactive relationship mapping
* CSV-based transaction analysis
* Detection of suspicious transaction patterns
* Identification of fraud rings and smurfing activities
* Dynamic graph visualization using React Flow

### 📊 Intelligence Dashboard

Centralized threat monitoring and investigation management.

* Real-time analytics and insights
* Historical investigation tracking
* Interactive charts and reports
* Secure investigation storage
* Data persistence using Firebase Firestore

## ⚙️ Installation & Setup

### Clone Repository

```bash
git clone https://github.com/your-username/raksha-ai.git
cd raksha-ai
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env.local` file:

```env
GEMINI_API_KEY=your_gemini_api_key
```

### Firebase Configuration

1. Create a Firebase Project.
2. Enable Authentication (Google and Email/Password).
3. Create a Firestore Database.
4. Add Firebase configuration values to your project.

### Run Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
